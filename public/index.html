주제
형식
분석 PC가 꺼져 있어요. 검색·스크랩북은 그대로 되고, 타임라인 분석과 영상 속 말 검색은 PC에서 ref 를 켜면 돼요.
여기에 놓으면 스크랩북에 올라가요

이용 안내

돈이 결제되는 기능은 없어요. 대신 몇몇 검색은 하루에 쓸 수 있는 양이 정해져 있어요.

마음껏 써도 되는 것 (무료)

  • 유튜브 쇼츠 검색 (하루 100번까지)
  • 영상 열어보기, 조회수·좋아요 보기, 스크랩·메모
  • 이미 분석된 영상의 타임라인, [영상 속 말] 검색
  • 3일 안에 누군가 했던 검색 (저장된 결과를 보여줘요)

하루 한도가 있는 것

  • 인스타·틱톡·핀터레스트·스레드 검색: 새 검색 한 번에 2, [전체]는 8을 써요
  • 하루 검색량은 모두가 똑같이 나눠 써요. 왼쪽 아래에서 남은 양을 볼 수 있어요
  • 필터(날짜·주제·형식)를 바꾸거나 [비슷한 영상] 탭을 열 때도 새 검색이에요
  • 다 쓰면 결제되는 게 아니라 새 검색만 막히고, 다음 날 다시 채워져요

앱처럼 쓰기

  • 왼쪽 메뉴(폰은 아래 탭)의 홈 화면에 추가를 누르면 기기별 방법이 나와요. 아이폰은 Safari, 안드로이드는 크롬에서 할 수 있어요
  • 카카오톡으로 받은 링크는 카톡 안 브라우저라 구글 로그인과 홈 화면 추가가 안 돼요. ⋯ → 다른 브라우저로 열기를 눌러 주세요

부탁드려요

  • 검색은 유튜브 쇼츠부터 해 주세요
  • 스크랩북은 함께 써요. 남이 저장한 건 지우지 말아 주세요
  • 받은 영상·썸네일은 참고용으로만 쓰고 다른 곳에 올리지 말아 주세요
  • 처음 보는 영상의 타임라인 분석은 운영 PC가 켜져 있을 때만 돼요
